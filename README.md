# RestartGen website

Plain HTML/CSS/JS, no build step. Hosted on GitHub Pages: every change pushed to the main branch goes live automatically.

## Files
- index.html, about.html, team.html, articles.html, contact.html – the five menu pages
- 404.html – page not found
- css/style.css – all styling (brand colours at the top)
- js/main.js – English/Greek switch and mobile menu
- assets/ – logos (SVG, traced from the brand files) and favicon

## Bilingual text
Every piece of text appears twice, side by side:
  <p lang="en">English text</p><p lang="el">Ελληνικό κείμενο</p>
Only the active language is shown. Edit both when you change something.
